# 语言包

本目录 JSON 使用 UTF-8：键为启动器源文案，值为译文。已有键应保持稳定；未完成的翻译直接省略，不用英文占位，以便语言选择器显示真实覆盖数。查询顺序：所选语言 → en_us → 源文案。

十种语言均覆盖当前目录的 220 条文案，包含长篇帮助、任务状态、确认弹窗与操作提示。新增八种语言未经母语审校；阿拉伯语终端 RTL、字形连接和双向混排仍待验证与适配，不应宣称完整阿拉伯语排版。目录完整并不表示底层错误、游戏日志或远程内容已翻译。

保持所有 `{id}`、`{scope}`、`{}` 等占位符及其数量一致，允许调整命名占位符的顺序；`{e:#}` 用于保留错误链。支持命名、顺序 / 数字位置参数和字面量双花括号，不支持任意 Rust 格式表达式。用户名称、路径、搜索结果等仅作为参数插入，不参与文案匹配或二次插值。

资源通过 include_str! 编入二进制，发布仍只需可执行文件。修改语言包后重新编译即可，无需新增运行脚本或随包配置。新增语言还须在 src/localization.rs 的 UiLanguage 注册原生名称、代码、游戏映射和内置资源。

本目录是本项目的原创文案翻译，使用项目 MIT 许可。HMCL 仅作架构和游戏语言兼容行为参考，未复制其翻译文件。
