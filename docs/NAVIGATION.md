# 导航结构

参考本地 HMCL 源码的 `ui/main/RootPage.java`、`ui/instances/GameInstancePage.java` 与 `GameListPopupMenu.java`：根页面组织账户、当前实例、实例列表、下载和设置，实例管理子页面共享一个明确的实例上下文。

```text
账户
  账户列表与切换、添加离线账户、微软登录
实例管理（绑定已选择的实例 ID）
  启动游戏
  游戏设置
  Mod 管理
  存档管理
  加载器 / 组件
    Fabric / Quilt / Forge / NeoForge
      具体加载器版本
  修复、Java 安装、启动诊断、游戏日志
  修改名称、复制、导出、移入回收站
实例列表
  搜索与选择
  Enter → 管理所选实例
  Space → 启动所选实例
下载
  官方版本、正式版 / 快照筛选、原版安装
设置
  全局游戏与下载设置
  检测本机 Java
  回收站
  任务日志
  导入整合包
  CurseForge API 密钥
```

宽终端显示左侧五项导航，窄终端改用顶部紧凑入口。启动时聚焦导航，上下选择入口，Enter / 右键进入内容区；内容区按左键返回导航，Tab / Shift+Tab 切换焦点。1–5 直达一级入口并进入内容区。上下选择当前菜单，Enter 打开，Esc 返回上一级并保留所选项；在一级内容页按 Esc 返回导航。弹窗优先处理 Esc；任务浮窗收起后任务继续运行。

实例管理绑定稳定 ID，而不是当前菜单的行号；更名不改变管理对象。已删除或缺失的实例会返回实例列表。本地与官方下载列表分别记忆搜索条件，避免在下载页沿用本地 Mod 实例名称筛选。

界面检查覆盖：五个一级入口与子页绘制、窄终端、过滤后的实例身份、设置返回、加载器类别返回、错误实例拒绝、工具菜单归属和列表搜索隔离。实际游戏启动验收范围继续见 ROADMAP.md。
