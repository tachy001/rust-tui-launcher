# 导航与工作台结构

TUI 采用**顶部五工作区标签 + 双栏主从工作台（Master-Detail Workbench）+ 键盘鼠标协同**结构，消除旧版多级菜单跳转与侧栏焦点陷阱：

```text
1 启动与实例（默认主页）
  ├─ 左栏：实例列表（实时搜索筛选、最近游玩标记、加载器徽章、Space 立即启动）
  └─ 右栏：实例工作台（绑定当前选中实例 ID，← / → 切换五个子页）
       ├─ 概览：启动游戏、检查修复、安装建议 Java、启动诊断、游戏日志、改名、复制、导出、回收
       ├─ 独立设置：14 项实例级覆盖参数（显式区分 [已覆盖] 与 [继承]），D 一键恢复继承
       ├─ Mod：本地启停 / 导入 / 备份移除恢复，Modrinth 在线搜索、选版本与检查更新
       ├─ 存档：实例存档列表、备份为 ZIP、从 ZIP 导入新存档
       └─ 组件：安装 Fabric / Quilt / Forge / NeoForge / OptiFine
2 下载中心
  ├─ 左栏：Mojang 官方版本目录（正式版 / 快照切换、关键词搜索、已安装标记）
  └─ 右栏：安装工作台（纯净原版、Fabric、NeoForge、Forge、Quilt、OptiFine、导入整合包）
3 账户管理
  ├─ 左栏：账户列表（微软正版 / 离线角色、当前生效状态）
  └─ 右栏：身份与凭证操作（切换账户、微软浏览器授权登录、新建离线角色、CurseForge 密钥、移除凭证）
4 全局设置
  ├─ 左栏：设置分类（游戏与启动、Java 与兼容、下载与整合包、通用与语言、全部设置、实例回收站）
  └─ 右栏：对应分类的实时设置表单（开关直切、镜像源快捷切换、多语言选择器）或实例回收站恢复列表
5 任务日志
  ├─ 顶部：实时后台任务监控卡片（进度条、速率 / 剩余时间、暂停 / 取消控制）
  └─ 主区：带行号与级别着色的滚动日志视图（支持历史锚定与横向平移，Esc 返回来源页）
```

## 交互原则

- **零焦点陷阱**：启动后直接聚焦实例列表，`↑↓` 浏览实例、右侧工作台实时联动预览，`Space` 一键启动游戏，`Enter` 或 `→` 进入右侧工作台。
- **全局直达**：任意非输入状态下按 `1–5`、`Tab / Shift+Tab` 或 `[ / ]` 直接切换顶部五个主工作区。
- **鼠标协同**：支持直接点击顶部工作区标签、工作台子标签、启动按钮和任意列表行（单击选中聚焦，再次点击已选中项执行操作），支持滚轮翻动列表与日志。
- **响应式降级**：宽终端并排展示左栏列表与右栏工作台；窄终端按当前面板焦点自动切换单栏全宽展示，`Esc` 返回左栏。
